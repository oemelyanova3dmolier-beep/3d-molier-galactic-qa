# Галактическая инспекция качества: файлы для размещения на сайте

## Что внутри
```
public/            файлы сайта (это нужно выложить на хостинг)
  index.html       дашборд (картинки и тексты внутри файла)
  storage.js       хранилище данных (общее или локальное)
  assets/theme.mp4 фоновая музыка
server.js          маленький сервер для общей игры (Node.js 16+, без зависимостей)
package.json       запуск: npm start
```

## Вариант 1. Общая игра (рекомендуется)
Нужен сервер или хостинг с Node.js 16 и новее.

1. Загрузите папку целиком на сервер.
2. Запустите, задав свой секретный ключ администратора:
   `ADMIN_KEY=ваш-секрет PORT=3000 node server.js`
   (на Windows: `set ADMIN_KEY=ваш-секрет && node server.js`)
3. Откройте сайт. Для постоянной работы используйте pm2, systemd или панель хостинга и обязательно включите HTTPS (через nginx или панель хостинга).
4. Один раз откройте страницу по адресу `https://ваш-сайт/?admin=ваш-секрет`. Ключ запомнится в браузере, и вы станете владельцем: в «Штабе модерации» появятся поля настройки.
5. Задайте PIN модераторов (6 и больше цифр, кнопка «Сохранить PIN») и в день старта нажмите «Начать формирование эскадрилий (сегодня)».
6. Передайте PIN модераторам. Участникам ничего вводить не нужно.

Данные лежат в `data/db.json`, скриншоты в `data/uploads/`. Делайте их резервную копию.

## Вариант 2. Обычный статический хостинг (только демо)
Загрузите содержимое папки `public/` в корень сайта. Игра откроется, но данные хранятся только в браузере каждого посетителя и между людьми не передаются. Подходит для показа внешнего вида, не для настоящей игры.

## Важно
- **PIN защищает интерфейс, а не данные.** Его хэш открыт, и технически подкованный участник может обойти проверку. Настройки (PIN, дата старта) защищены ключом администратора на сервере.
- **Музыка.** Трек из саундтрека «Звёздных войн» защищён авторским правом. Прежде чем публиковать сайт, проверьте лицензию. Чтобы заменить трек, положите свой файл в `public/assets/theme.mp4` или поменяйте путь в `index.html` (тег `<audio id="bgm">`). Чтобы убрать музыку, удалите этот тег.
- Смена дня происходит в 10:00 по Москве, выходные не считаются.
- Тексты заданий находятся в `index.html` в массиве `DAYS`, цель эскадрильи и общая целостность крейсера в константах `GOAL` и `HPT`.
- Если хотите хранить данные на готовом сервисе (Firebase, Supabase), адаптер `storage.js` нужно переписать под него.
